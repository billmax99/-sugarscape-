## 這是什麼?

1996 年,Epstein & Axtell 做了一個著名的電腦實驗 **Sugarscape(糖域)**:
一片長著糖山的地圖,一群只會"朝看得見的食物走過去"的小人,沒有任何劇情設計——
跑著跑著,**貧富分化、階層定居、市場價格,全都自己湧現了出來**。

本專案把這個實驗做成了**你可以親自投胎進去玩**的遊戲:

- 🎲 **抽籤出生**:出生地、天賦、壽命、乾糧全是籤——可能生在糖山中心,也可能生在寸草不生的荒原
- 🚶 **親自活一遍**:點格子走位、採集、交易、攢錢讀書(視野+1,看得更遠)
- 💀 **死亡總結**:高光/侷限分析、比 AI 託管多活多少回合、你在世時世界發生了什麼大事
- 📚 **生命之書**:歷世帳本,點任何一行重看那一世的總結
- 👻 **死後附身**:意識跳進任何一個活人,看看富人/窮人是怎麼活的

**出身決定的是難度,不是結局。** 你可以親手驗證這句話。

## 實驗能力(給想認真玩的人)

| 功能 | 能觀察什麼 |
|---|---|
| 📈 觀察面板 | 基尼係數、貧困率、窮人翻身率、富人佔比,即時大字+解讀 |
| 📊 流動性追蹤 | 窮/中/富三群組描圈上地圖,親眼看誰能爬上山;翻身/保持/下跌矩陣 |
| 🧪 對照實驗 | 抽籤世界 vs 人人天賦相同的世界賽跑 300 回合,自動出結論 |
| ⚙ 世界參數 | 稅收、教育價格、部落戰爭、擁擠天災、地形三模式、純糖世界……全是實驗旋鈕 |
| ⏱ 定時觀察 | 設定 N 回合連跑,主人公死了世界也繼續 |
| 👁 示範模式 | 自動播放+大事字幕,適合投影給別人看 |

## 自檢

開啟 `sugarscape.html?test=1` 會自動跑 34 項斷言(交易雙贏、NaN 防禦、生態穩態、生育繼承、地形約束、純糖世界出身籤等),
編年史第一條顯示 `自檢 34/34 通過 ✅` 即為健康。
手機版用 `sugarscape-手机版.html?test=1`,自檢 32 項。
