# 糖域・人生リスタート — 実験マニュアル(日本語)

> 「転生シミュレーター」:誰も管理しない世界で、貧富の差がどう勝手に育つかを見る。
> 遊び方:人生を引く → 生きる → 死んで総括を見る → また引く。

---

## 1. 原理(どこから来たか)

1996年、**Epstein と Axtell** が有名なコンピュータ実験 **Sugarscape(糖域)** を行いました。
物語は一切なし。やったことは3つだけ:

1. **糖の山**がある地図を描く(マスによって糖の量はまちまち);
2. 「見える食べ物へ歩く、食べる、消費する」ことしかできない**小人**を放す;
3. 再生ボタンを押して、ただ見る。

**驚きの結果**:こんな単純なルールで——
- **貧富の差**が生まれた(誰も「金持ち」「貧乏」を設計していないのに);
- 強者は肥沃な土地を占め、弱者は周縁へ押しやられた;
- 最初全員平等でも差は広がり、自然には消えない。

**ひとことで:大きな不平等には悪人も陰謀も要らない。「資源の偏り+各自が自分の食料を探す」という2つの単純なルールだけで自動的に現れる。** これがこの実験の最も深い発見です。

後に研究者は2つ目の食料**香料**を別の山に追加し、住人は**取引**しなければ生きられなくなった——すると**市場と価格**が自発的に生まれました。

## 3. 遊び方(30秒)

![Welcome card](../images/welcome.png)


1. **人生を引く** — 出生地/素質/寿命/持ち金はぜんぶ運。気に入らなければ引き直し・場所指定・階級指定(貧/中流/富裕)も可。

![Birth report](../images/birth.png)

2. **生きる** — 「▶ この人生を始める」→ マスをクリックして移動(採集は自動)。お金が貯まったら勉強(視界+1)。隣人に寄ると自動取引。
3. **死と向き合う** — 総括カード:ハイライト/限界/あなたの存命中の世界の出来事/(ブラインドモード)素質カード公開。一生ごとに 📚 人生の書 へ。行をクリックで総括を見直せる。

![Death summary](../images/death.png)

4. **3つの再出発** — 新しい人生を引く / 死後に「👻 憑依」で任意の住人に入る / 世界を作り直す。

## 4. 定番の実験(研究者のように遊ぶ)

- **出生地比較**:山の上5回、荒野5回、寿命を比較。
- **勉強比較**:同じスタートで、勉強する側としない側。
- **平等実験**:🧪 300ターン2世界対決。頻出の結論:*同一素質の世界の方がむしろ不平等になりやすい——不平等の主因は「場所と運」*。

![A/B experiment](../images/exp.png)

- **流動性追跡**:📊 出身階級の輪を地図に描き、誰が山に登れるか見る。

![Mobility tracking](../images/cohort.png)

- **ルール切替**(⚙):富の再分配、無料教育、部族戦争、過密疫病、純糖世界(取引なし)…
- **👁 デモモード**:字幕付きで自動再生、人に見せるのに最適。

## 5. 数字の読み方

![Live stats panel](../images/obs.png)


- **ジニ係数**:0=全員同じ貧しさ、1=一人が全部所有。**正常:0→0.2〜0.4に上昇して安定。** 曲線が上り続けることこそ「デザイナーなしの不平等の自然発生」の証拠。
- **人口**:100〜400で安定。50未満で移民が補充される。
- **糖価格**:1近辺で変動。誰が決めたのでもなく、住人の交渉から生まれる。
- **富の分配**:上位10%が30〜60%が常態。100%近辺=独占、10%近辺=均等な若い世界。
- **貧困→中流の上昇率**:通常30〜50%。*努力は効く、しかし天井がある。*

## 6. 子ども向けまとめ

キャンディを校庭の隅2か所にだけ山積みして、先生が去る遊び場を想像して。近くに立った子は満腹、遠くの子は走り回って少ししか取れない。誰も「貧乏」に決めたわけではない——キャンディに届かない子が、自然と貧乏になった。このゲームはあなた自身がその子になって試すもの:**始まる場所を選べないなら、どう生きるのが一番良いか?**

遊び終えれば分かる:**公平は自然には存在しない——誰かが差に気づき(ジニ係数)、ルールを変えなければ(⚙ パラメータ)。**
